📘 Справочная система OCS — Online-Cinema System

Документация для оператора (контент-менеджера и администратора).

1. Начало работы

Регистрация: Нажмите «Регистрация» → введите email, пароль, имя → подтвердите.
Вход: Кнопка «Вход» → email + пароль → «Войти».
Настройка профиля: Нажмите на аватар → «Профиль» → изменить имя, пароль.

2. Поиск и каталог фильмов

Фильтр по жанру: Выберите жанр в выпадающем списке.
Поиск: Введите название в строке поиска.
Сортировка: По году, рейтингу или популярности.
Пагинация: Используйте кнопки «Вперёд/Назад» внизу каталога.

3. Просмотр фильмов

Управление плеером: Play/Pause (Пробел), громкость (↑/↓), полный экран (F).
Сохранение прогресса: Видео запоминает место остановки.
Перемотка: Клик по шкале времени или стрелки ← →.
Субтитры: Кнопка CC в плеере (если доступны).

4. Управление подпиской

Тарифы: Базовый (199₽/мес) — SD, Премиум (499₽/мес) — 4K + устройств: 4.
Оплата: В разделе «Подписка» → выбрать тариф → ввести карту → оплатить.
Отмена подписки: «Моя подписка» → «Отменить» → подтвердить.
Продление: Автоматически каждый месяц. При ошибке — уведомление на email.

5. Администрирование

Добавление фильма: /admin → «Фильмы» → «Добавить» → заполнить форму → загрузить постер и видео.
Управление пользователями: /admin → «Пользователи» → блокировка / смена роли.
Просмотр статистики: /admin → «Статистика» → просмотры, доходы, подписки.
Модерация контента: Редактирование метаданных, смена постера, удаление.

⚡ Горячие клавиши

F1 — открыть эту справку
Ctrl + K — быстрый поиск фильма
Esc — закрыть плеер/модальное окно
